# Core Libraries

Follow the rules defined in [.claude/rules-snippets/core-libraries.md](../rules-snippets/core-libraries.md).

Key points:
- Use @open-sunsama/utils for common utilities.
- Use TanStack Query for state management and Tailwind CSS for styling.
- Use Radix UI for UI components; check existing components before creating new ones.
