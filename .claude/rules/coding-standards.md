# Coding Standards

Follow the rules defined in [.claude/rules-snippets/coding-standards.md](../rules-snippets/coding-standards.md).

Key points:
- All code must follow TypeScript type safety rules and Hono and React conventions.
- Keep functions focused and manageable (under 50-75 lines).
- Use try-catch for async operations; leverage Hono and React error utilities.
