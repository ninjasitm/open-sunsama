# UI Accessibility

Follow the rules defined in [.claude/rules-snippets/ui-accessibility.md](../rules-snippets/ui-accessibility.md).

Key points:
- Develop with a mobile-first approach.
- Adhere to WCAG 2.1 AA accessibility standards.
- Use semantic HTML elements and ensure keyboard navigation.
- Use loading states during async operations.
