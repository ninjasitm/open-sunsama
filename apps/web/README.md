# @open-sunsama/web

The React 19 + Vite web app for Open Sunsama. Runs on port 3000 and talks to the API on port 3001.

- Local development: `bun run dev:local` from the repository root (see [AGENTS.md](AGENTS.md) for the rules).
- Tests: `bunx turbo run test --filter=@open-sunsama/web`
- Patterns, structure, and gotchas: [AGENTS.md](AGENTS.md)
