# @open-sunsama/desktop

The Tauri v2 desktop app for Open Sunsama. It wraps the web app with a system tray, global hotkeys, notifications, and auto-launch.

- Shell development: `cd apps/desktop && bun run dev`
- Build: `bunx turbo run build --filter=@open-sunsama/desktop`
- Release: `bun run release` from the repository root
- Rules and gotchas: [AGENTS.md](AGENTS.md)
