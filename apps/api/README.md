# @open-sunsama/api

The Hono REST API for Open Sunsama, with the remote MCP endpoint at `/mcp`. Runs on port 3001.

- Local development: `bun run dev:local` from the repository root (see [AGENTS.md](AGENTS.md) for the rules).
- Tests: `bunx turbo run test --filter=@open-sunsama/api`
- Patterns, structure, and gotchas: [AGENTS.md](AGENTS.md)
